How this works

This proves timing, not true sample-level phase cancellation. Browser audio has real round-trip latency, typically 100ms or more, so this test cannot react instantly to a single sound. Once a sound repeats several times, QZ detects the rhythm, predicts when the next cycle should occur, and schedules an anti-noise burst for that predicted moment. This brings the timing logic previously tested with the FxLMS simulation into a live-audio test.
