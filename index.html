How this works

This proves timing, not true sample-level phase cancellation — browser audio has real round-trip latency (typically 100ms+), so this can't react instantly to a single sound. What it does: once a sound repeats a few times, it locks onto the rhythm and fires an anti-noise burst aimed at when the next cycle should land — the same logic the FxLMS simulation validated on paper, now running on live audio.
