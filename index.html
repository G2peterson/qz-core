QZ Audio Test

Point the top edge of the phone toward the unwanted sound. Push the phone toward that sound until QZ displays GOT IT. Start QZ Audio to activate the phone microphone and send an inverted audio signal to the connected headphones or earbuds. This is an experimental signal-path test. Bluetooth latency may prevent true phase cancellation. The timing and output controls are included so we can determine what the hardware actually allows. Start with a low QZ output level.
